CSV Format

The CSV file should have the following columns (header row required):

  • Name - Product name (required)
  • Category - Category name (required, will be created if doesn't exist)
  • Description - Product description
  • Pack Description - Pack description
  • Price Ex GST - Price excluding GST
  • Price Inc GST - Price including GST
  • Available - Available for sale (True/False)
  • Stock Quantity - Current stock quantity
  • Image - Filename of the product image (optional, see below)

Example CSV:

Name,Category,Description,Pack Description,Price Ex GST,Price Inc GST,Available,Stock Quantity,Image
Italian Mozzarella,Cheese,Fresh mozzarella from Italy,500g x 12,45.00,49.50,True,50,mozzarella.jpg
Plain Flour,Flour,All-purpose white flour,1kg x 10,25.00,27.50,True,100,

Note: If a product with the same name and category already exists, it will be updated with the new data.

Importing images: upload the image files to the product_images_import folder on the server first, then reference each file by its exact filename in the Image column. Leave this column blank to leave a product's image unchanged. If a filename isn't found, the row still imports but a warning is shown and the image is skipped.
